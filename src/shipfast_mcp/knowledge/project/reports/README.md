# reports/ — trang báo cáo xem trực tiếp trên máy

Trang HTML báo cáo, duyệt (kèm ảnh) để PO mở thẳng bằng trình duyệt. Không đưa lên dịch vụ ngoài.

| Quy ước | Nội dung |
|---|---|
| Mỗi báo cáo một thư mục | `reports/<wave>-<topic>/index.html` và ảnh cạnh bên, ví dụ `reports/w01-current-state/` |
| Tự chứa, chạy offline | Chỉ dùng đường dẫn tương đối; không tải font, script, ảnh từ internet |
| Mở trên Windows (WSL) | `\\wsl.localhost\<distro>\<đường dẫn repo>\reports\<thư mục>\index.html` |
| Git | Nội dung thư mục bị gitignore, trừ file này. Kết quả cần lưu lâu dài (quyết định duyệt, số liệu) ghi vào `docs/` |

| Báo cáo | Nội dung |
|---|---|
