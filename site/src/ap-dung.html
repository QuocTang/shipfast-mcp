Dùng shipfast-mcp

shipfast-mcp là MCP server dựng bộ khung tài liệu vào dự án, cấp mã, kiểm hồ sơ và nâng cấp khung bằng three-way merge.

01Cài đặt

Claude Code (plugin)
/plugin install shipfast --marketplace QuocTang/shipfast-mcp
Claude Code (MCP)
claude mcp add shipfast -- uvx shipfast-mcp
Client MCP khác
uvx shipfast-mcp

02Prompt

PromptKhi nào dùng
initRepo mới: dựng khung và chạy W01, AI đề xuất và phản biện stack, PO chốt
adoptDự án đang có code: dựng khung, giữ tài liệu và quyết định sẵn có
upgradeKhung có bản mới: dry run, gộp ba phía, trình chỗ xung đột

03Tool

ToolViệc
scaffold_projectDựng khung tài liệu, có dry run
upgradeNâng cấp khung bằng three-way merge
statusTrạng thái: bảng wave, wave đang mở, vấn đề chờ PO, backlog, quyết định giả định
checkKiểm hồ sơ: biến khung còn sót, liên kết hỏng, wave đóng thiếu rút kinh nghiệm, bảng wave lệch
open_waveMở hồ sơ wave mới
new_decisionGhi quyết định mới theo mẫu
next_codeCấp mã không trùng
create_departmentLập bộ phận và subagent
refresh_departmentsLàm mới subagent bộ phận theo mẫu mới
read_guideĐọc tài liệu hướng dẫn
