# CONTRACTS — Thành phần, lệnh chuẩn, contract

> Contract **đang chạy** giữa các phần của hệ thống: thành phần, lệnh, API, sự kiện, schema dùng chung, cổng. `../01_design/` mô tả ý định; file này mô tả cái đang chạy.
> Mâu thuẫn về luật sản phẩm thì quyết định ở `../05_decisions/` thắng. Mâu thuẫn về **tên field, đường dẫn, định dạng** giữa tài liệu thiết kế và file này thì **file này cùng code contract thắng**.
> Đổi contract: sửa file này **và** code contract trong cùng một lượt, ghi một dòng vào nhật ký §3, báo phần dùng nó. Stack và thành phần chốt ở wave W01 (`KT-001`).
