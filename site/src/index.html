Cài đặt

Các bước bắt đầu

  1. 1

    Cài uv

    shipfast chạy bằng uvx, không cần cài Python thủ công.

    curl -LsSf https://astral.sh/uv/install.sh | sh
  2. 2

    Thêm shipfast vào client MCP

    Claude Code dùng plugin; Cursor, VS Code, Codex khai một server stdio chạy uvx shipfast-mcp.

    /plugin install shipfast --marketplace QuocTang/shipfast-mcp
  3. 3

    Gọi prompt init hoặc adopt

    Repo mới gọi init. Dự án đang có code gọi adopt.

    /mcp__shipfast__init
  4. 4

    Trả lời theo mã vấn đề

    Orchestrator trình từng vấn đề kèm phương án và phản biện. PO trả lời theo mã, ví dụ "W01-02: A", và nói "chốt" khi đồng ý phạm vi.

  5. 5

    Theo dõi và nâng cấp

    Hỏi "đang tới đâu" để xem trạng thái. Khi có phiên bản mới, gọi upgrade.

    /mcp__shipfast__upgrade
